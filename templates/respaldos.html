Respaldos automáticos de Azure

Azure SQL Database genera respaldos completos, diferenciales y del log de forma automática y permite restaurar la base a un punto en el tiempo.

La restauración se realiza desde el portal de Azure (base de datos > Restaurar). Desde esta pantalla solo se consulta el historial.

Recomendaciones
  • Completo: diario, fuera del horario del buffet.
  • Diferencial: a mediodía, si hubo mucho movimiento.
  • Log: cada hora durante la atención (modelo FULL).
  • Copie los archivos a un disco externo o a la nube una vez por semana.
